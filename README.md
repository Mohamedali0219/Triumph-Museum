# Triumph Museum - The Grand Egyptian Museum Website

A premium, interactive, and multilingual web application for the **Triumph Museum** (The Grand Egyptian Museum), showcasing the glorious history of the Egyptian Army through a modern digital experience.

## 🌟 Key Features

*   **Interactive Historical Gallery**: Explore 13 specialized rooms, each featuring detailed historical narratives in both Arabic and English.
*   **Multilingual Support**: A custom i18n engine allowing seamless switching between Arabic, English, and other languages.
*   **Cinematic Presentation**: Full-width video backgrounds and cinematic headers that provide an immersive experience.
*   **Hologram Interface**: A dedicated section for interactive exploration of museum rooms.
*   **Premium Booking System**: A custom-designed ticket booking interface with real-time price displays and responsive layout.
*   **Contact & Social Integration**: A professional contact section with form validation and social media connectivity.
*   **Rich Animations**: Smooth scroll reveals, hover effects, and a custom branded loading screen with a unique "zoom-out" exit animation.
*   **Fully Responsive**: Meticulously crafted for all screen sizes, from mobile phones to high-resolution desktops.

## 🛠️ Technology Stack

*   **Frontend**: Vanilla HTML5, CSS3, and JavaScript (ES6+).
*   **Icons**: Font Awesome 6.4.0.
*   **Typography**: Google Fonts (Tajawal for Arabic, Playfair Display for headers).
*   **Styling**: Custom CSS with a focus on gold and dark-section aesthetics to reflect the museum's prestige.

## 🚀 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Mohamedali0219/Museum.git
    ```
2.  **Open the project**:
    Simply open `index.html` in any modern web browser.

> [!TIP]
> **Recommended Execution**: For the best experience and to avoid browser security restrictions related to the `file://` protocol (especially with the interactive gallery), it is recommended to run the project using a local server (e.g., VS Code's "Live Server" extension or `npx serve`).

## 📁 Project Structure

*   `index.html`: Main entry point and page structure.
*   `css/style.css`: Comprehensive design system and responsive styles.
*   `js/main.js`: Core logic for animations, language switching, and modal interactions.
*   `js/translations.js`: Centralized data store for all multilingual content.
*   `lang/`: Directory for future external translation JSON files.
